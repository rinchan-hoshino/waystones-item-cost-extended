# Locked MixinGradle producer

This minimal Maven repository contains the exact `org.spongepowered.mixin` plugin marker and `org.spongepowered:mixingradle:0.7-SNAPSHOT` producer used by the Forge legacy profiles. Sponge publishes no non-snapshot `0.7` plugin coordinate. `lock.json` records SHA-512 and size for every upstream artifact so a changing snapshot cannot silently alter release builds.

Authoritative upstream: `https://repo.spongepowered.org/repository/maven-public/`
